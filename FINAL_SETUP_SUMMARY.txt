## 🔐 How It Works

### Login
```
User credentials → Backend /auth/login → JWT token
                 ↓
              Stored in Zustand (localStorage)
                 ↓
            Used for all future requests
```

### Protected Requests
```
Any API call → Automatically adds header:
              Authorization: Bearer <token>
                 ↓
         Backend validates token
                 ↓
       If valid: Process request
       If invalid (401): Redirect to login
```

### Error Handling
```
401 Unauthorized → Clear token, redirect to login
403 Forbidden    → Show "Access Denied"
Network Error    → Show backend URL and error details
```

```javascript

  getAllCases: async () => {
```

## 🚨 Troubleshooting

| Problem | Solution |
|---------|----------|
| "Backend unreachable" | Verify IP in .env, check backend running |
| "Invalid credentials" | Check backend user exists, verify password |
| "Access Denied (403)" | User needs permissions in backend |
| "Session expired (401)" | Login again, token may have expired |
| CORS error | Backend must allow http://localhost:5173 |
| Data not showing | Check Network tab (F12), look for 401/403 |
| File upload fails | Check backend file size limits |
| Hash mismatch | Verify backend hash computation logic |
