================================================================================
TROUBLESHOOTING
================================================================================

ERROR: "Backend unreachable at http://..."
  Solution:
    1. Check IP is correct in .env file
    2. Verify backend is running on backend laptop
    3. Verify both laptops on same network
    4. Check firewall allows port 5000

ERROR: "Invalid credentials"
  Solution:
    1. Verify credentials exist in backend database
    2. Check password is exactly correct (case-sensitive)
    3. Try creating new user in backend

ERROR: "Access Denied / 403"
  Solution:
    1. User exists but lacks permissions
    2. Contact admin to grant permissions
    3. Check user role in backend

ERROR: "Session expired / 401"
  Solution:
    1. Token expired, login again
    2. Clear browser cache: F12 → Application → Clear All
    3. Try fresh login

ERROR: CORS Error in console
  Solution:
    1. Backend CORS not configured for frontend
    2. Backend must allow: http://localhost:5173
    3. Contact backend developer to enable CORS

ERROR: Blank dashboard after login
  Solution:
    1. Open F12 (Developer Tools)
    2. Check Network tab for failed requests
    3. Check Console tab for errors
    4. Check if 401/403 errors present
