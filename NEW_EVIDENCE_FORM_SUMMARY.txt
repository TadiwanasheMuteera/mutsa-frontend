🔄 DATA FLOW

1. Component Mount
   ↓
2. Parse URL: caseId from useParams()
   ↓
3. useQuery: Fetch case details from /cases/:caseId
   ↓
4. useAuthStore: Get logged-in user
   ↓
5. Initialize Form with defaults:
   - collectedBy = user.name
   - collectionDate = current datetime
   ↓
6. User interacts with form
   ↓
7a. File Selection:
    - Drag or browse file
    - computeSHA256(file) called
    - Hash computed client-side
    - Hash displayed once ready
   ↓
7b. Form Submission:
    - Validate all required fields
    - Check Chain of Custody checkbox
    - useMutation POST to /cases/:caseId/evidence
    ↓
8. On Success:
   - Invalidate React Query caches
   - Navigate to /cases/:caseId
   - Display success message
   ↓
9. On Error:
   - Display error message
   - Show field-level errors
   - Remain on form for correction

📡 API REQUIREMENTS

Backend Endpoints Needed:

1. GET /api/cases/:caseId
   Response: { id, title, description, ... }

2. POST /api/cases/:caseId/evidence
   Body: {
     description: string,
     type: string,
     source: string,
     collectionDate: ISO 8601,
     collectionLocation: string,
     collectedBy: string,
     notes: string,
     hash: string (SHA-256)
   }

3. POST /api/evidence/:caseId/upload (optional)
   Content-Type: multipart/form-data
   Body: { file: File }
