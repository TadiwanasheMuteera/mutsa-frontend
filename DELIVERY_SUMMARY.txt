## 🔐 How API Calls Work

### Authentication
```javascript
// Login
POST /auth/login {email, password}
→ Returns {token, user}
→ Token stored in localStorage

// All future requests include:
Authorization: Bearer <token>
```

### Error Handling
```javascript
401 Unauthorized → Clear token, redirect to login
403 Forbidden → Show "Access Denied"
Network Error → Show backend URL for debugging
```

### Configuration
```javascript
// All API calls use:
VITE_API_BASE_URL + endpoint
// Examples:
GET {VITE_API_BASE_URL}/cases
POST {VITE_API_BASE_URL}/cases/:id/evidence
```
